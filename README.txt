Welcome to Goosegame, a python game similar to the Dutch game "Ganzenbord".
This game is designed to be played by two players on a single device.
When a player has finished its turn, they pass the device to the next player.

We assume the following software to be installed on your device:
- Windows 11 (any version)
- PyCharm 2024.1.1 (Community Edition)
- Anaconda package library (Anaconda is connected to Pycharm)


How to run this code and play the game:
1. place 'GooseGame.zip' in a reachable, logical directory on your device
2. Unpack 'GooseGame.zip'.
3. Start pycharm software
4. Look for the folder "GooseGame" and open.
5. check if the 'GooseGame' interpreter is selected
6. Navigate in the GooseGamefolder to 'Game_runner.py'
7. Run 'Game_runner.py'

When downloading the GooseGame it may happen that the picture names change.
Make sure that the Gooseboard picture is called 'ganzenbord2.jpg' and the picture of a goose meme is called '3.jpeg'.
